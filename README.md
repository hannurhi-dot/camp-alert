# 생림오토캠핑장 빈자리 감시 (폰 알림)

김해 생림오토캠핑장(camp.xticket.kr) 예약 사이트를 **5분마다 자동으로 확인**해서,
원하는 날짜에 예약 가능한 자리가 생기면 **휴대폰으로 알림**을 보냅니다.

> LLM(클로드)을 매번 돌리는 방식이 아니라 **일반 스크립트**라서, 실행해도 **토큰/요금이 들지 않습니다.**
> 사이트에 5분마다 가벼운 조회 요청 몇 개만 보냅니다.

---

## 지금 상태 (2026-09-01 기준)

요청한 4개 주말(10/2·10/16·10/23·10/30 체크인, 각 2박3일)은 **전부 매진**입니다.
- 금요일 밤은 자리가 많은데 **토요일 밤(10/3·10/17·10/24·10/31)이 0** 이라 2박3일이 안 됩니다.
- 즉 **토요일 밤 취소분이 하나 나오는 순간** 알림이 갑니다. (잔디·데크·파쇄석 3구역 모두 감시)

---

## 준비 (딱 한 번, 5분)

### 1. 폰에 ntfy 앱 설치

- 안드로이드: Play스토어에서 **ntfy**
- 아이폰: App Store에서 **ntfy**
- (앱 없이 폰 브라우저로 보고 싶으면 `https://ntfy.sh/여기에-내토픽` 주소를 즐겨찾기 해도 됩니다)

### 2. 나만의 토픽 이름 정하기

`saengnim-camp-` 뒤에 **아무도 못 맞출 랜덤 문자열**을 붙이세요.
예: `saengnim-camp-h7yq2m8x`

- ntfy 앱을 열고 **+** → 방금 정한 토픽 이름을 그대로 입력해 **구독(Subscribe)**

### 3. 스크립트에 토픽 넣기

`camp_check.py` 파일을 메모장으로 열어서 윗부분의 이 줄을 찾아 고칩니다:

```python
NTFY_TOPIC = os.environ.get("NTFY_TOPIC", "saengnim-camp-CHANGE-ME-9f3a7")
```

`"saengnim-camp-CHANGE-ME-9f3a7"` 부분을 **2번에서 정한 토픽**으로 바꿔 저장:

```python
NTFY_TOPIC = os.environ.get("NTFY_TOPIC", "saengnim-camp-h7yq2m8x")
```

### 4. 연결 테스트

`send_test.bat` 더블클릭 → 폰에 "테스트 알림"이 오면 성공.

## 실행 방법 A — 내 컴퓨터에서 5분마다 (권장, 간단)

`install_task.bat` **더블클릭**.

- 윈도우 작업 스케줄러에 "생림캠핑감시" 작업이 등록되고, **5분마다 조용히(창 없이)** 실행됩니다.
- 등록 직후 한 번 바로 실행합니다.
- **컴퓨터가 켜져 있는 동안만** 돕니다. (절전/잠자기 상태면 그동안은 멈춤 → 필요하면 전원 설정에서 절전 해제)
- 등록이 안 되면: `install_task.bat` 을 **우클릭 → 관리자 권한으로 실행**

**중지하려면**: `uninstall_task.bat` 더블클릭.

**지금 상태만 보고 싶으면**: `check_now.bat` 더블클릭 (알림은 안 감).

**로그**: `camp_check.log` 파일에 실행 기록이 쌓입니다.

---

## 실행 방법 B — 컴퓨터를 꺼도 되는 방법 (GitHub Actions, 무료)

깃허브 계정이 필요합니다. 클라우드에서 5분마다 실행됩니다.

1. 깃허브에서 **새 저장소(repository)** 생성 (Private 권장).
2. 이 폴더의 파일 전체를 그 저장소에 업로드
   (`camp_check.py` 와 `.github/workflows/camp-check.yml` 이 반드시 포함돼야 함).
3. 저장소 **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `NTFY_TOPIC`
   - Secret: 위에서 정한 토픽 (예: `saengnim-camp-h7yq2m8x`)
4. **Actions** 탭 → 워크플로가 보이면 활성화. `Run workflow` 로 수동 테스트 1회.

참고:
- 깃허브 예약 실행은 혼잡하면 **5~15분 늦게** 돌기도 합니다.
- 저장소에 **60일간 아무 활동이 없으면** 예약 실행이 자동 비활성화됩니다 (가끔 커밋하거나 수동 실행하면 유지).
- 방법 A와 B를 **동시에** 돌려도 됩니다 (중복 알림은 최대 1시간에 1번으로 제한됨).

## 날짜·조건 바꾸기

`camp_check.py` 위쪽 `TARGETS` 를 편집:

```python
TARGETS = [
    {"checkin": "20261002", "nights": 2},   # 체크인 20261002, 2박3일
    {"checkin": "20261016", "nights": 2},
    # 1박2일도 받고 싶으면 이렇게 추가:
    # {"checkin": "20261017", "nights": 1},
]
```

- `checkin` = 체크인 날짜(YYYYMMDD), `nights` = 숙박 일수(박).
- 특정 구역만 원하면 `FACILITIES` 에서 필요 없는 줄을 지우세요 (잔디=0001, 데크=0002, 파쇄석=0004).
- `RENOTIFY_MINUTES` = 자리가 계속 열려 있을 때 재알림 간격(기본 60분).
- `HEARTBEAT_HOURS` = 하루 1번 "감시 작동 중" 조용한 알림(0이면 끔).

## 알아둘 점

- 이 스크립트는 **빈자리를 알려주기만** 합니다. **예약·결제·본인인증은 직접** 하셔야 합니다.
  알림의 링크를 눌러 바로 예약 화면으로 갑니다.
- 취소분은 경쟁이 붙으면 **몇 분 안에 다시 마감**될 수 있습니다. 알림 오면 바로 움직이세요.
- 예약 단계에 CAPTCHA(자동입력 방지문자)가 있으면 그 부분은 사람이 해야 합니다.
- 사이트 구조가 바뀌면 스크립트가 동작을 멈출 수 있습니다. `camp_check.log` 에 오류가 계속 찍히면 알려주세요.
